
# Student Task Manager

## Project Description
Student Task Manager is a Python-based console application designed to help students manage their daily academic tasks.

## Features
- Add new tasks
- Display all tasks
- Mark tasks as completed
- Delete tasks
- View task status

## Technologies Used
- Python 3
- Git
- GitHub

## Setup Instructions
1. Install Python 3.
2. Clone this repository.
3. Open the project directory.
4. Run the application using:

```bash
python app.py
```

## Usage
Select an option from the application menu:

1. Add Task
2. Display Tasks
3. Complete Task
4. Delete Task
5. Exit
